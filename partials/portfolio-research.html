MPASE Interactive Genome Browser

Visual analytics tool for comparative analysis of reconstructed 3D genome structures from Hi-C data, integrating spatial organization with gene expression and chromatin accessibility. Aligns 27 Hi-C chromatin structures (uninfected and virally infected conditions at 12, 18, and 24hrs) via PCA and ICP into a shared coordinate frame. Three coordinated views: 3D genome structure panel for side-by-side comparison across conditions, shape analysis panel with HDR and point-fraction (PF) shape abstractions across XY/YZ/XZ projections, and a temporal dynamics panel linking gene expression and accessibility changes over time. Evaluated with 8 participants (SUS 88.44).

Stack: TypeScript, React, Redux, Web Workers, D3.js, Three.js, WebGL, Python, NumPy, scikit-learn

MPASE Python Toolkit

Python package (Multi-Point Alignment and Shape Extraction) for quantitative structural analysis of 3D genome point clouds. Implements a three-stage alignment pipeline: centroid normalization, PCA-based pre-alignment, and trimmed ICP refinement into a shared coordinate frame. Provides two complementary shape abstractions: HDR (bootstrap aggregation + Gaussian KDE + mass thresholds) and point-fraction (KDE scoring + rasterization + morphological cleanup) across XY/YZ/XZ projections. Includes quantitative comparison metrics: IoU, Hausdorff distance, and mean boundary distance, with multi-scale representations at multiple abstraction levels.

Stack: Python, NumPy, scikit-learn, PCA, ICP, HDR Modeling, Statistical Metrics

Neurosurgery Network Pattern Analysis

Visual computing framework for analyzing epilepsy EEG ensemble data to support neurosurgical planning. Introduces a dynamic community detection algorithm (modified Louvain) and social network abstraction to extract conserved electrode spike propagation patterns across 2-5 recorded sessions (70-120 electrodes per patient). Four coordinated views: 3D brain network with patient-specific anatomy and electrode communities, 2D patch network for within/across-patch propagation, EEG panel with duckDB for fast loading of >1GB per-session files, and a patch summary encoding spike frequency, onset, and spread. Evaluated with 10 neurologists and surgeons across 4 medical centers (SUS 90.0).

Stack: HTML, CSS, JS, React, D3.js, Three.js, Python, Flask, duckDB, RESTful API Design

mEnergy: Multi-device mHealth Platform

Web-based clinical dashboard for near real-time remote monitoring of metabolic health in head and neck cancer survivors, integrating Fitbit Sense 2 (smartwatch) and Withings Body+ (smart scale) via OAuth 2.0. Four coordinated views: a Demographics and PRO panel, a Body Composition panel tracking sarcopenia risk via Lean/Fat Mass Index (LMI/FMI), a Sleep Analysis panel visualizing SpO2 and heart rate for apnea detection, and an Activity panel for daily activity goals. Project page.

Stack: HTML, CSS, JS, React, D3.js, OAuth 2.0 Web APIs

Contrail Visual Analysis & Detection

Visual computing framework for analyzing contrail ensemble data from multiple HPC aircraft engine simulations (>100 GiB). The back-end leverages a contrail-formation criterion, novel geometric shape detection via the α-shape algorithm, and DBSCAN clustering to detect and track contrail structures over time. The front-end provides four coordinated views: I/O parameter exploration via custom colored-tile glyphs, 3D volume rendering via WebGL ray casting, a contrail evolution tracking graph, and a shape similarity view with Kiviat diagrams. Evaluated with domain experts. Published at IEEE VIS 2022 and featured in IEEE Computing Edge Magazine and UIC Newsletter.

Stack: Python, pandas, scikit-learn, Flask, NumPy, HTML, CSS, JS, D3.js, WebGL

HNC-PREDICTOR

Three-view clinical decision-support dashboard for head and neck cancer radiotherapy outcome prediction: an Input Variables Panel with automated AJCC-8th stage detection, a 10-year Outcome Prediction View using Cox regression models for overall survival, local control, and regional control, and a Model-based Cohort Stratification View for high/low risk group comparison. Trained and validated on 4,611 patients from three international centers (MDACC, UMCG, PMH). Publicly deployed at risk-calculator.evl.uic.edu; evaluated with clinicians across multiple countries (SUS score 87.81, excellent usability).

Stack: HTML, CSS, JS, React, D3.js, Python, Flask, R, NumPy, RESTful API Design
